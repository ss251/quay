Functions

Live on testnetRuns on

A function is Rust compiled to WASI. OutLayer runs it in a TEE worker, and the contract keeps a registry of your functions and a record of every result. A function can hold a secret and make outbound HTTPS calls. There is no JavaScript runtime.

Commands

Terminal
quay functions deploy moderate
quay secrets set MOD_API_KEY --fn moderate
quay functions invoke digest '{}'
quay functions logs moderate

How Harbour Board uses it

  1. A member adds a post. The posts collection has on_add: moderate, so the contract records a request in the _fn collection.
  2. OutLayer runs moderate with the post and the MOD_API_KEY secret. It checks blocked words and fetches a preview for any link.
  3. The result lands back on the contract. A post marked hide: true leaves / and /api/posts, and /posts/9 answers 404.

The post is saved before the check comes back. In our runs the check took 5 to 17 seconds.

This is the result moderate wrote for run 24, read from the _fn collection:

  "name": "moderate",
  "caller": "e2e-4eb351a1.harbour-board.testnet",
  "ok": true,

What you trust

OutLayer is one operator's TEE network. Secrets are decrypted inside its enclave, so you trust that enclave and that operator. There is no drop-in replacement. You can run the same logic on your own server with its own key, as quay relay serve does, or leave functions out. Without them, posts still land, previews stay empty and scheduled results stop.
