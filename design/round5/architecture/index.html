Architecture

One NEAR account holds the app. Everything else is a service that reads it, writes to it or runs code for it. This page lists which is which, and what breaks when a service goes away.

What is on chain

The contract stores these, and any RPC node can read them without a Quay service. Large files are the exception. The release stores an https URL and a sha256, and anyone can check the hash.

  • Releases and the production pointerlive
  • Docs, collections and their ruleslive on the Board
  • Routes and templates, sealed in a releaselive on the Board
  • Memberslive on the Board
  • Products and receiptslive on the Board
  • Function registry and function resultslive on the Board
  • Cron jobsset, not armed

Versioned with a release, and not

A release seals files, routes and templates together, and quay rollback swaps all three.

Docs, collection rules, products, members, receipts, function code and secrets, relay settings and cron jobs are live state. A rollback does not touch them, and quay up says so before it runs.
