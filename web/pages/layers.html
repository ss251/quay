Layers

A site on one NEAR testnet account can hold its pages, its data, its sign-in and its scheduled work. Each layer below lists the commands and what has been shown to work.

Status on 2026-11-11

Layers marked live were run on testnet on one sample, Harbour Board, account harbour-board.testnet, contract 3.0.0. Each section says how to check it without a key. The two older accounts, quay-esc0v902.testnet and quay-65nqd3rn.testnet, still run 2.0.0. The command help below is generated from the CLI in this build.

{{i:info}}

Collections, docs, rules, products, members, function code and cron settings are live state. Only files, routes and templates are sealed with a release, so quay rollback restores those three and never your data.

To check a view yourself, run curl against https://test.rpc.fastnear.com with a call_function request. The repository README has a one-line view helper, and scripts/judge.sh step 9 runs every check below.

Site

Live A folder becomes a sealed release. Production is a pointer.

Terminal
quay init
quay deploy ./site -m "harbour office"
quay promote 1
quay rollback

Read the quickstart and the command reference. Proof: the transactions in the repository README.

Gateway

Live The gateway turns a browser request into a web4_get view call. This site is served by one running on Cloudflare Workers. The same code runs on your machine, in a container, or under Deno and Bun. On 2026-11-10 the public testnet.page gateway answered every account with HTTP 400 for several hours, which is why this exists.

Terminal
quay gateway --account <account>
# serving <account> at http://127.0.0.1:8787/
cd gateway/worker && npx wrangler deploy
{{HELP:gateway}}

Data

Live A collection holds JSON docs. Its rules say who may add, who pays for storage, and whether the owner can hide a doc. With --payer site a visitor needs no NEAR. Check: list_collections and db_list on harbour-board.testnet.

Terminal
quay db fund 2
quay db collection set posts --write anyone --payer site --moderated
quay db add posts '{"title":"Tide table is up"}'
quay db list posts --limit 10
{{HELP:db}}

Members and sign-in

Live A member is an account named <name>.<site>, created with no NEAR. Six exist on the Board: check list_members. Sign-in is a NEP-413 signature checked off chain. A member's signed session key is verified by verifySignIn in the sandbox suite. Wallet sign-in through near-connect is pending: it has not been shown on testnet.

Terminal
quay members list
quay members close
quay members open
{{HELP:members}}

Relay

Live A relayer sends a delegate action the member signed, and pays the gas. Its policy refuses any deposit, so only site-paid writes work. Two hosts serve one protocol: quay relay serve, a Node process, and an OutLayer function with no server. Members joined and posted through both. The OutLayer host needs a payment key that sits in the page, so anyone who reads the page can spend it. Scope it and keep the balance small. A call took 5 to 17 seconds and stalled before a fix. The relayer is its own account and its balance is the spend limit. Spikes: relayed delegate, session key delegate, a delegate whose deposit the relayer paid.

Terminal
quay relay create --near 0.5
quay relay serve --port 8788
quay relay deploy
quay relay status
{{HELP:relay}}

Functions

Live A function is Rust compiled to WASI and run on OutLayer's TEE workers. It can hold a secret and make outbound HTTPS calls. There is no JavaScript runtime. The Board's moderate runs on every post: a secret round-tripped through an authenticated echo API, it attaches a link preview, and it hid a spam post. digest ran by hand through fn_call. The digest run. Check: fn_list, and db_list on the _fn collection. A run takes 5 to 17 seconds, and OutLayer is one operator.

Terminal
quay functions deploy moderate
quay secrets set MOD_API_KEY --fn moderate
quay functions invoke digest '{}'
quay functions logs moderate
{{HELP:functions}} {{HELP:secrets}}

Routes

Live A release can declare routes: a pattern, a collection, and a template that is a file in the same release. The contract fills the template in web4_get, so a page is complete HTML without JavaScript. Routes live in quay.json and are applied by quay up. Templates escape every value. There is no raw output. Check: curl https://harbour-board.testnet.page/api/posts.

quay.json
"routes": [
  { "pattern": "/", "kind": "list", "collection": "posts", "template": "templates/home.html", "limit": 10, "order": "desc" },
  { "pattern": "/posts/:id", "kind": "doc", "collection": "posts", "template": "templates/post.html" },
  { "pattern": "/api/posts", "kind": "json", "collection": "posts" }
]

quay up --dry-run checks every route and template before anything is sent.

Large files

Live on FastFS A file over files.external_over bytes goes to FastFS, which stores it for gas only. The release holds its https URL and sha256. The Board's 493,183 byte hero photo is served through the gateway, and its sha256 is 16cca451…8ccf. NEARFS accepted uploads (9xj3bLha…) and never served them on testnet, so it is not the default. Pinata and Filebase stores exist and were never run against the live services.

quay.json
"files": { "external_over": 65536, "store": "fastfs" }

Pass --store fastfs|nearfs|pinata|filebase to quay up to override it.

Payments

Live, test USDC only A product has a price in NEAR or in one NEP-141 token, and a grant: pin a doc for a time, or record a receipt. Receipts are a system collection that routes can read. The Board has one pin paid in NEAR and one in usdc.fakes.testnet, which anyone can mint. Circle USDC is not used. Check: list_receipts.

Terminal
quay products set pin --name "Pin for a day" --price 0.1 --grant pin --pin-seconds 86400
quay products list
quay receipts
{{HELP:products}}

Cron

Set, not armed OutLayer has no scheduler, so the contract keeps a chain of yielded promises alive. Each hop runs about every 2 minutes and costs about 2.25 Tgas, so 1 PGas lasts about 14.5 hours. After that the chain stops until a transaction arms it again. The Board's digest job is set but the chain is not armed, because arming needs about 1.1 NEAR liquid. Spikes with a plain contract: EaBzBzUg… and 7Ff67z7N….

Terminal
quay cron add "every 60m" digest
quay cron arm
quay cron status
{{HELP:cron}}

quay up

Live One command applies quay.json: functions, collection rules, products, the members setting and cron jobs, then it deploys the site folder with its routes and promotes it. It never arms cron. --dry-run prints the plan and changes nothing. The Board was deployed with it.

Terminal
quay up --dry-run
quay up -m "harbour board"
{{HELP:up}}
