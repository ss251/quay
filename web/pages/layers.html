Layers

A site on one NEAR testnet account can hold its pages, its data, its sign-in and its scheduled work. Each layer below lists the commands and what has been shown to work.

Status on 2026-11-11

The two live accounts, quay-esc0v902.testnet and quay-65nqd3rn.testnet, still run contract 2.0.0: releases and the production pointer. The layers from Data to quay up are written and tested in the repository, and are not deployed to a testnet account yet. Each section says so. The command help below is generated from the CLI in this build, so a command that is missing from the build says that it is missing.

{{i:info}}

Collections, docs, rules, products, members, function code and cron settings are live state. Only files, routes and templates are sealed with a release, so quay rollback restores those three and never your data.

Site

Live A folder becomes a sealed release. Production is a pointer.

Terminal
quay init
quay deploy ./site -m "first look"
quay promote 1
quay rollback

Read the quickstart and the command reference. Proof: the transactions in the repository README.

Gateway

Live The gateway turns a browser request into a web4_get view call. This site is served by one running on Cloudflare Workers. The same code runs on your machine, in a container, or under Deno and Bun. On 2026-11-10 the public testnet.page gateway answered every account with HTTP 400 for several hours, which is why this exists.

Terminal
quay gateway --account <account>
# serving <account> at http://127.0.0.1:8787/
cd gateway/worker && npx wrangler deploy

Data

Pending deploy A collection holds JSON docs. Its rules say who may add, who pays for storage, and whether the owner can hide a doc. With --payer site a visitor needs no NEAR.

Terminal
quay db fund 2
quay db collection set posts --write anyone --payer site --moderated
quay db add posts '{"title":"Tide table is up"}'
quay db list posts --limit 10
{{HELP:db}}

Members and sign-in

Pending deploy A member is an account named <name>.<site>, created with no NEAR. Sign-in is a NEP-413 signature checked off chain, by a wallet or by a member key kept in the browser. A zero-balance sub-account was created on testnet in CEshJvn3…. That was a spike, not this contract.

Terminal
quay members list
quay members close
quay members open
{{HELP:members}}

Relay

Pending deploy A relayer signs nothing for the user. It sends a delegate action the member signed, and pays the gas. Its policy refuses any deposit, so only site-paid writes work. The relayer is a separate account and its balance is the spend limit. Spikes on testnet: a relayed delegate HpNGtV3W…, a function-call session key delegate BkN8S7Zx…, and a delegate whose deposit the relayer had to pay 4zVRVvNh….

Terminal
quay relay create --near 0.5
quay relay serve --port 8788
quay relay status
{{HELP:relay}}

Functions

Pending deploy A function is Rust compiled to WASI, run on OutLayer's TEE workers, and called from the contract. It can hold a secret and make outbound HTTPS calls. There is no JavaScript runtime. On testnet a contract called an OutLayer function with a secret and outbound HTTPS in A2JT46x6…. That was a spike.

{{HELP:functions}} {{HELP:secrets}}

Routes

Pending deploy A release can declare routes: a pattern, a collection, and a template that is a file in the same release. The contract fills the template in web4_get, so a page is complete HTML without JavaScript. Routes live in quay.json and are applied by quay up. Templates escape every value. There is no raw output.

quay.json
"routes": [
  { "pattern": "/", "kind": "list", "collection": "posts", "template": "templates/home.html", "limit": 10, "order": "desc" },
  { "pattern": "/posts/:id", "kind": "doc", "collection": "posts", "template": "templates/post.html" },
  { "pattern": "/api/posts", "kind": "json", "collection": "posts" }
]

quay up --dry-run checks every route and template before anything is sent.

Large files

Blocked on testnet A file over files.external_over bytes is stored off chain, and the release holds its CID and sha256. NEARFS on testnet accepted an upload in 9xj3bLha… and did not serve it: it answered 404 for hours on 2026-11-10. Pinata and Filebase stores exist and take an API key from the environment. They were not run against the live services.

quay.json
"files": { "external_over": 65536, "store": "nearfs" }

Pass --store nearfs|pinata|filebase to quay up to override it.

Payments

Pending deploy A product has a price in NEAR or in one NEP-141 token, and a grant: pin a doc for a time, or record a receipt. Receipts are a system collection that routes can read.

Terminal
quay products set pin --name "Pin for a day" --price 0.1 --grant pin --pin-seconds 86400
quay products list
quay receipts
{{HELP:products}}

Cron

Pending deploy OutLayer has no scheduler, so the contract keeps a chain of yielded promises alive. Each hop runs about every 2 minutes and costs about 2.25 Tgas, so 1 PGas lasts about 14.5 hours. After that the chain stops until a transaction arms it again. Spikes on testnet: EaBzBzUg… and 7Ff67z7N….

Terminal
quay cron add "every 60m" digest
quay cron arm
quay cron status
{{HELP:cron}}

quay up

Pending deploy One command applies quay.json: functions, collection rules, products, the members setting and cron jobs, then it deploys the site folder with its routes and promotes it. It never arms cron. --dry-run prints the plan and changes nothing.

Terminal
quay up --dry-run
quay up -m "harbour board"
{{HELP:up}}
